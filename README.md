# NC Viewer 🌊

해류·수온·염분 등 해양 예측 NetCDF(`.nc`) 파일을 브라우저에서 클릭 몇 번으로
확인하는 간단한 도구입니다.

- 파일을 열면 안에 어떤 변수(수온, 염분, 해류 등)가 들어있는지 표로 보여줍니다.
- 변수를 선택하고 깊이/시간을 슬라이더로 고르면 지도 위에 색으로 그려줍니다.
- `uo`(동서 해류), `vo`(남북 해류) 파일을 같이 넣어두면 해류 방향 화살표도 볼 수 있습니다.
- 파일명에 `202608`처럼 연월(YYYYMM)이 들어있으면 자동으로 "2026년 08월"로 보기 좋게 표시하고,
  같은 변수의 파일이 2개 이상 있으면 두 시점(예: 8월 예측 vs 10월 예측)의 차이 지도도 볼 수 있습니다.
- 업로드 용량 제한은 2GB까지 (`.streamlit/config.toml`).

## 설치 & 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

실행하면 브라우저가 자동으로 열립니다 (안 열리면 터미널에 뜨는
`http://localhost:8501` 주소로 접속).

## 사용 방법

1. 왼쪽 사이드바에서 `.nc` 파일을 업로드하거나,
   `data/` 폴더에 파일을 미리 넣어두고 새로고침합니다.
2. 파일을 선택하면 위쪽에 변수 목록/차원/단위가 자동으로 표시됩니다.
3. 그리고 싶은 변수를 고르고, 필요하면 깊이/시간을 조절합니다.
4. 지도가 그려지면 PNG로 다운로드할 수 있습니다.

## 폴더 구조

```
nc_viewer/
├── app.py            # 메인 앱 (여기만 고치면 됩니다)
├── requirements.txt
├── data/             # 여기에 .nc 파일을 넣으세요 (깃에는 올라가지 않음)
└── README.md
```
